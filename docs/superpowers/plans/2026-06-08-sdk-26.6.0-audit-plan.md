# SDK 26.6.0 Audit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Update the MCP server to ride on `@actual-app/api@26.6.0`, swap the notes workaround to the new public API, and resolve any drift between our `SdkActualClient` adapter and the current SDK surface.

**Architecture:** Discovery-driven audit. We bump the SDK, generate a typed-surface diff between `26.5.0` and `26.6.0`, then for each diff entry we classify it (Absorb / Propagate / Adopt-new / Skip) and only implement changes the audit table flags. Known refactor targets (notes API, fire-and-forget transactions, tracking-budget fields) are handled with full TDD; unknown findings are handled by the per-finding template that follows the audit table.

**Tech Stack:** TypeScript, `@actual-app/api@^26.6.0` (target), `@modelcontextprotocol/sdk@^1.27.0`, Vitest (unit + integration configs), GitHub Actions CI, release-please.

**Branch:** `feat/sdk-26.6.0-audit` (already created off `main`, spec committed at `e7c9aed`).

**Spec:** `docs/superpowers/specs/2026-06-08-sdk-26.6.0-audit-design.md`.

  }
  async setNote(id: string, note: string): Promise<void> {
